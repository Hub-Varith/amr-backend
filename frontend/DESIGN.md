# DNAGen frontend

An editorial research workspace: navy ink (#182f40), warm cream paper (#f5f2e9), muted blue accents. Source Serif 4 for expressive headings, IBM Plex Sans for explanation, IBM Plex Mono for measurements and labels. Retain the existing brand and React/Vite stack.

Use a clear product statement above the fold, a single primary demo action, spacious ruled layouts and a report preview. No testimonial or performance claims without project evidence. Keep MIC units visible. Example data must be explicitly fictional; file checks must not pretend to run predictions. Preserve the lab-confirmation disclaimer.

Use semantic links/buttons, labeled inputs, visible focus, responsive single-column layouts and reduced-motion support. Keep source changes local unless asked to commit.

References consulted: https://getdesign.md/ ; https://github.com/voltagent/awesome-design-md ; https://github.com/pbakaus/impeccable ; https://github.com/nextlevelbuilder/ui-ux-pro-max-skill . Adapt principles rather than reproducing another brand. No external template code copied.
